# 공사노트

수량산출 엑셀에 단가를 연결해 설계내역서와 공사비를 작성하는 Windows 데스크톱 프로그램입니다. 다산소프트 또는 콘엑스의 공식 제품이 아닌 독립 프로그램입니다.

## 다운로드

[최신 Windows 설치파일](https://github.com/dsa123345a-oss/gongsa-note/releases/latest/download/gongsa-note-setup.exe)을 내려받아 설치한 뒤 바탕화면의 공사노트를 실행하세요. 10월 메인 DB와 추가 상수도 DB가 기본 포함되어 있습니다. 버전별 변경 내용과 소스는 [릴리스](https://github.com/dsa123345a-oss/gongsa-note/releases)에서 확인할 수 있습니다.

처음 설치하거나 구버전에서 실행 오류가 발생하면 설치파일을 사용하세요. `gongsa-note-windows-x64.zip`은 프로그램 내부 업데이트용입니다. 탐색기로 직접 압축을 풀어 실행하면 다운로드 출처 표시 때문에 .NET DLL 로드가 차단될 수 있습니다. 기존에 저장한 `.gongsa` 파일은 설치 후 작업 열기에서 열 수 있습니다.

프로그램의 업데이트 메뉴는 이 저장소의 새 정식 배포를 확인합니다. 다운로드한 파일의 크기와 SHA-256을 확인한 뒤 업데이트하며, 기존 공사 자료와 등록한 단가 DB는 보존합니다. GitHub 저장소가 연결되기 전의 구버전은 위 배포 파일을 한 번 직접 받아 실행해야 합니다.

## 실행과 자료 보관

Windows 10/11 64비트와 Microsoft Edge WebView2 Runtime이 필요합니다. 배포 ZIP을 쓰기 가능한 폴더에 풀고 공사노트.exe를 실행하세요. 함께 들어 있는 _internal_버전 폴더도 필요합니다. EXE 옆의 `공사노트 자료` 폴더에 공사 내역, 등록 단가와 공사 보관함이 저장됩니다. 이 폴더를 함께 백업하세요. 작업 저장 메뉴로 개별 공사도 보관할 수 있습니다.

배포본에는 지정된 `2026-10-main.estx`와 `상수도공사메인(26년)소형감압변 수정.ebkx` 두 DB가 포함됩니다. 처음 실행하면 자동 등록됩니다. 산출 구성은 추가 DB를 우선하고, 노임·자재·장비 기준가격은 10월 메인을 사용합니다. 최신 기준에서 찾지 못하는 자원은 기존 가격을 유지하고 근거에 표시합니다. 기존 저장 DB가 있거나 사용자가 DB 목록을 비운 경우에는 재등록하거나 덮어쓰지 않습니다. 다른 `.estx`, `.ebkx`도 자료실에서 추가할 수 있습니다. 자료는 이 컴퓨터에서 처리하며 외부에 전송하지 않습니다.

단가산출은 EST 원문의 작업조건·작업량 분수식·중간 소계를 보존해 표시합니다. 화면의 단가 상세와 미리보기·PDF·엑셀은 같은 산출근거를 사용합니다. 가격을 갱신한 항목은 현재 적용 가격과 결과를 표시합니다. 수량식을 수정한 경우 원문 작업조건과 실제 적용식을 구분하며, 재계산을 검증하지 못한 원문은 저장 근거임을 표시합니다. 공사 파일에는 사용한 중첩 산출근거도 함께 저장됩니다.

상수도 신규급수·긴급보수 연결 기준도 프로그램에 기본 탑재되어 별도의 학습 파일이 필요 없습니다. 품목·규격·단위·공종의 연결 사례만 포함하며, 학습에 사용한 공사명·신청인·주소·과거 금액은 포함하지 않습니다. 현재 단가 DB에 있는 품목을 찾아 계산하므로 과거 공사비를 복사하지 않습니다. `단가 자동 연결`에서 공사 구분을 바꾸거나 학습 기준 사용을 끌 수 있습니다. 공사명으로 구분하지 못하면 공통 기준을 사용합니다. 사례가 부족하거나 서로 다른 항목에 연결된 경우 및 관경 누락은 자동 선택하지 않습니다. `미검토 자동 연결도 다시 추천`으로 이전 자동 결과를 비교할 수 있으며, 직접 연결하거나 검토 완료한 항목은 유지합니다. 자동 연결 결과가 다시 기본 학습에 누적되지는 않습니다.

## 인쇄와 PDF

상단 `인쇄` 또는 F5를 누르면 먼저 출력할 항목을 선택합니다. 선택한 문서는 미리보기 왼쪽 목록 순서로 출력하며, 다음에 열 때 선택을 유지합니다. 미리보기의 `인쇄 항목`에서 다시 선택할 수 있습니다. 전체 선택·전체 해제와 자료 없는 항목 비활성화를 지원합니다.

미리보기에서 원가계산서·내역서총괄표·내역서·일위대가·단가산출·기계경비·자재·노임 등을 고르고 페이지 이동·배율·시작번호를 조절합니다. `인쇄 옵션`은 현재 문서의 방향·여백·글자 크기·행 높이와 항목/공종/지정행 페이지 나누기를 설정합니다. `기본양식 저장/열기`는 공사 보관함에 설정을 저장합니다.

`PDF 저장`은 EXE의 로컬 PDF 생성 기능을 사용합니다. Windows의 굴림 글꼴을 읽어 PDF에 포함하므로 다른 PC에서도 글자가 유지됩니다. `인쇄`와 `프린터 설정`은 시스템 인쇄창을 엽니다. A4, 배율 100%, 머리글/바닥글 없음으로 설정하세요. 실제 종이의 위치에는 프린터 비인쇄 여백이 영향을 줄 수 있습니다. 미리보기/PDF와 제공된 스캔 원본의 100% 동일성은 아직 검증되지 않았습니다.

현재 단가와 원본 저장 산식이 일치하지 않으면 근거 확인 문구를 표시합니다. 현재 공사비를 원본 PDF 숫자로 대체하지 않습니다. 기존 표지·설계설명·예정공정 등은 `기타 문서 출력`에서 사용할 수 있습니다.

## 주요 기능

신규급수 수량산출서 가져오기 창에서 `신규급수 수수료 추가`를 선택하면 동일 신청·설계·검사 건에 설계·시공자재검사·준공검사 수수료를 각각 1건 추가합니다. 사용자가 확정한 운영 기준에 따라 관급자재의 계량기 중 가장 큰 구경을 적용하며, 계량기 개수를 곱하지 않습니다. 25mm까지 합계 17,000원, 32mm까지 20,000원, 40mm 이상 23,000원입니다. 선택한 수량 시트에 관급자재가 없으면 관로도 등 다른 시트의 관급자재 구역을 찾아 보충하고 출처를 표시합니다. 관급 계량기가 없거나 구경이 불명확하면 관로 구경으로 대신 계산하지 않고 확인 후 입력합니다. 이전 급수관 기준으로 저장한 수수료는 이 창에서 다시 적용하면 계량기 기준으로 갱신됩니다. `작업도구 → 신규급수 수수료` 또는 내역 하단의 같은 버튼에서 구경을 수정할 수 있습니다. 자동 수수료는 낙찰률·제경비·부가세에서 제외하며 원인자부담금과 별도로 총공사비에 합산됩니다. 기존 수동 수수료는 명시적으로 교체하기 전까지 유지됩니다. 여러 파일이나 긴급보수는 자동으로 한 신청으로 묶지 않습니다.

왼쪽 아래 작업 탭에서 일위대가·단가산출·기계경비·자재단가·노임단가를 누르면 현재 공사에 사용한 목록과 산출근거를 좌우로 표시합니다. 검색·위아래 방향키로 항목을 선택하고, 가운데 구분선을 끌어 목록 너비를 조절합니다. `산출근거 수정` 후 저장하면 같은 탭에 새 단가를 표시합니다. 구성 자원은 `사용 내역에서 수정`으로 연결되고, `내역 위치` 또는 `내역서` 탭으로 내역에 돌아갑니다.

`파일 → 단가 근거표 엑셀`에서 현재 공사에 쓰인 일위단가표·기계경비단가산출표·자재단가표·노임단가표를 별도로 저장합니다. `파일 → 엑셀 내보내기`는 내부 검토용으로 네 근거표와 내역·원가계산을 함께 연결합니다. 노란 입력 칸을 바꾸면 해당 엑셀 안에서 연결된 수식이 재계산됩니다. 검증할 수 없는 원본 산식은 ‘적용 단가 직접 입력’으로 구분하고 현재 단가를 보존합니다. 엑셀 수정값이 프로그램 작업에 자동으로 역수입되지는 않습니다.

프로그램에서는 내역의 단가 금액 → 구성·잡비 편집 → `저장 · 내역서에 적용`으로 수정하며, 해당 내역의 기존 수량·낙찰률을 유지하고 공사비를 갱신합니다. `업체 전달용 엑셀`에는 근거표를 넣지 않고 기존 원가계산서·내역서총괄표·내역서 3개 시트만 저장합니다.

- 수량산출 XLSX 가져오기, 공종별 내역 편집과 집계, 비목별 절사, 엑셀 출력
- EST 자료 조회, 일위대가·단가산출 편집, 잡비·수식·변수, 단가 갱신
- 낙찰률, 관급 구분, 제경비, 원가계산, 도급액 역산, 조달수수료
- 공사 보관함, 블록 편집, 조사단가, 자원 동원표, 기계경비·운반 산식
- 표지·설계설명·내역·원가계산·예정공정 인쇄, 표시 밀도와 열 순서 설정
- 근거자료 낙찰과 원단가 복원, 관급·직접금액 유지, 상하위 이중 적용 방지
- 엑셀 열 지정으로 수량·내역·단가 DB 가져오기, 원본 위치와 금액 불일치 보존
- 폴더 안의 ESTX/EBKX 자료 일괄 추가, 같은 파일명은 하위 경로로 구분

근거 낙찰은 `적산 도구 → 근거자료 낙찰 · 원단가 복원`에서 대상 선택 → 계산 결과 검토 → 적용 순서로 사용합니다. 선택 내역의 내역 낙찰률은 100%로 전환하고, 하위 구성 단가에 비율을 적용해 잡비·소계를 재계산합니다. 원본 대조가 통과하지 않은 복합 근거는 보류됩니다. 100%를 적용하면 원단가를 복원합니다.

`엑셀 열 지정 가져오기`는 시트·행 범위·열을 직접 지정할 수 있습니다. 합계 단가만 있는 표는 계상 비목을 선택해야 합니다. 저장 계산값이 없는 수식이나 원본 금액과 불일치하는 내역은 확정 금액으로 숨기지 않습니다. 내역의 자유 형식 산식 전체를 가져오는 기능은 아닙니다.

지원 범위는 앱의 `적산 도구 → 구현 범위`에서 확인하세요. 모든 EST 기능과 파일을 지원하지는 않습니다. 원본 금액과 대조되지 않은 구성은 자동 편집을 제한합니다. EST 원본 형식으로 되돌려 저장하는 기능은 없습니다. 미연결 항목이 있는 합계는 부분합이며, 공사 조건에 맞는 요율은 사용자가 검토해야 합니다.

## 업데이트

`적산 도구 → 프로그램 업데이트`에서 확인 → 다운로드 → 저장 후 재시작 순서로 적용합니다. 임의 자동 설치는 하지 않습니다. 정식 버전만 허용하고 파일 크기와 SHA-256을 검증합니다. 연결 오류는 최대 3번 자동 재시도하며 다운로드 취소 후 다시 받을 수 있습니다. 이미 받은 정상 파일은 새 버전 확인 후 재사용합니다. 설치 전 자료를 `공사노트 자료/updates/버전/업데이트 전 자료.sqlite3`에 백업합니다. 기존 EXE는 `.previous.exe`로 보관하며, 교체 또는 재실행 요청 실패 시 이전 프로그램을 다시 엽니다. 파일 교체 도중에도 실행 파일 경로가 비는 구간이 없도록 처리합니다. 공사·단가 DB는 교체 대상이 아닙니다. 새 버전이 화면을 준비했다는 응답까지 확인합니다. 응답 전에 프로세스가 종료되면 이전 EXE로 복구합니다. 실행 중인 프로그램은 시간 초과만으로 강제 종료하지 않습니다. 실행 후의 모든 오류를 감지하는 기능은 아닙니다.

배포 저장소는 `dsa123345a-oss/gongsa-note`입니다. 새 정식 릴리스에 포함된 `update.json`과 Windows ZIP을 기준으로 업데이트를 확인합니다.

## 개발 및 검사

Python 3.13, Node.js 22 이상을 기준으로 합니다.

```powershell
python -m pip install -r requirements.txt
node --test tests/*.test.mjs
python -m unittest discover -s tests -p "*_test.py" -v
python desktop.py
```

실제 자료를 사용하는 검사는 `EST_MONTH_PATH`, `EST_ADDED_PATH`, `EST_PROJECT_PATH`, `EST_SAVED_PROJECT_PATH`로 지정할 수 있습니다. 지정된 기본 DB 두 개 외의 개인 공사자료는 저장소에 추가하지 마세요.

## EXE 및 배포 파일 만들기

```powershell
python -m PyInstaller --noconfirm --distpath release --workpath build gongsa-note.spec
python tools/prepare_release.py release/공사노트 release/public
```

배포 준비 스크립트는 개인 공사자료를 제외하고, `release.json`에 이름·크기·SHA-256이 선언된 기본 DB 두 개만 허용합니다. 원본과 기본 DB가 다르거나 누락되면 중단합니다. 기본 DB는 소스 ZIP에도 포함되어 같은 설정으로 재빌드할 수 있습니다.

새 버전은 다음 순서로 배포합니다.

1. `release.json`의 `repository`가 `dsa123345a-oss/gongsa-note`인지 확인합니다.
2. 버전을 올리고 검사 후 위 명령으로 새 EXE와 배포 파일을 만듭니다.
3. 해당 버전의 GitHub 정식 Release(태그 `v0.13.37` 형식)에 설치파일 `gongsa-note-setup.exe`, 업데이트용 `gongsa-note-windows-x64.zip`, `update.json`, 소스 ZIP을 함께 올립니다.
4. 처음 설치하거나 연결 전 구버전에서는 설치파일을 사용합니다. 이후 버전부터 앱 안에서 업데이트할 수 있습니다.

선언된 기본 DB 외의 개인 공사자료, 사용자 SQLite, 실행 로그는 Git이나 Release에 올리지 않습니다. 공개 배포 EXE에는 코드 서명이 적용되어 있지 않습니다.

배포 방식은 v0.7.0부터 단일 압축 EXE 대신 EXE와 버전별 runtime 폴더를 사용합니다. 업데이트는 새 runtime을 완성한 뒤 EXE만 교체하며, 이전 runtime을 보존합니다.

## 업체 전달 엑셀 양식

업체 전달용 엑셀에서 신규급수(3.착공) 또는 긴급보수(2.착공) 양식을 선택합니다. 원가계산서·내역서총괄표·내역서 3개 시트를 기존 착공 양식의 글꼴과 셀 크기, 인쇄 설정으로 생성합니다. 공종 수에 따라 행이 늘어나며, 기존 양식에 없던 제경비는 같은 서식으로 추가됩니다. 원본 양식은 XLS지만 생성 파일은 XLSX입니다. 설계 원본과 수신업체 전달본을 구분하고, 낙찰률 적용 및 관급·수수료 제외는 전달본에만 적용합니다.


## 내역서 범위 선택

왼쪽 행 번호를 클릭하고 Shift+클릭하면 연속 범위, Ctrl+클릭하면 떨어진 행을 추가하거나 해제합니다. Ctrl+Shift+클릭은 기존 선택에 범위를 추가합니다. 행 번호에 초점이 있을 때 Shift+↑/↓로 범위 조절, Ctrl+A로 표시된 행 전체 선택, Esc로 선택 해제, Delete로 선택 행 삭제가 가능합니다. 선택 행 복사·행 삭제·선택 일괄 편집 버튼을 사용할 수 있으며 되살리기로 복구합니다. 필터 또는 접기로 숨긴 행은 선택에 포함하지 않습니다.


### 공사 파일 더블클릭 열기

새 버전의 공사노트.exe를 한 번 실행하면 `.gongsa` 파일에 공사노트 아이콘과 열기 동작이 등록됩니다. 실행파일과 함께 제공된 내부 폴더를 한 폴더에 두세요. 기존 `.gongsa.json`은 작업 열기로 열고 저장하기를 눌러 `.gongsa` 파일로 저장하면 됩니다. 기존 JSON은 보존됩니다. 프로그램이 켜져 있을 때 다른 공사를 더블클릭하면 현재 창에서 저장 여부를 확인한 뒤 엽니다. 프로그램 폴더를 옮겼다면 옮긴 위치에서 공사노트.exe를 한 번 실행하세요.
